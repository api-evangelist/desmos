# Desmos

> Desmos (Desmos Studio PBC) is the dead-simple way to embed rich, interactive math into a web page or web app. Its developer product is a client-side JavaScript API that mounts embeddable graphing, 3D, geometry, scientific, and four-function calculators, controlled through a browser object model. Authentication is a single API key passed on the script URL. Founded 2011 by Eli Luberoff; the calculators operate as an independent public benefit corporation and remain free to all.
